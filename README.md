# 🪙 Tap Game

Простая игра-тапалка с 3D-монеткой, скинами, экономикой и онлайн-счётчиком.

## 🎮 Функции
- 3D-монетка с анимацией
- 10 скинов (от 50 до 10 млн монет)
- Ежедневный бонус
- Таблица лидеров
- Автокликер
- Инвестиции и рулетка
- Офлайн-доход
- Достижения
- Реальный онлайн-счётчик

- Flask (сервер)
- Render (хостинг)
